# Архив постов автора

Здесь лежат тексты, которые реально вышли в канале. Написаны автором, не агентом.

Правила работы с папкой:

- Не редактируем и не «улучшаем» эти файлы. Это слепок голоса, а не черновик.
- Не копируем текст целиком в новые посты. Смотрим на поведение текста: длина строк,
  порядок блоков, где шутка, где цифра, где ссылка.
- Готовые разборы «почему это работает» лежат в `viora-studio/reference/examples.md`.
- Сначала читаем `INDEX.md`, а не все файлы подряд. Там рубрика, охват, пересылки
  и строка «что именно сработало». Полный текст открываем только по нужной строке.
  Так экономится контекст.

Важно про ссылки: в архиве ярлыки вроде `[ТЫК]` местами стоят без URL — так текст
сохранился из канала. В новых постах ссылка всегда внутри ярлыка: `[ТЫК](url)`.
