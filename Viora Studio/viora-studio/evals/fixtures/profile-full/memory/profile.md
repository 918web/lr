# Профиль автора

Заполняется один раз, на первом запуске. Скилл спрашивает пустые
обязательные поля одним сообщением и больше их не спрашивает.

Посмотреть: python3 tools/memory.py profile show
Что пусто: python3 tools/memory.py profile missing
Записать: python3 tools/memory.py profile set город=Астрахань

Файл едет вместе со скиллом. Если репозиторий публичный, внеси его в .gitignore.

## Поля

| Поле | Ключ | Значение | Обязательное | Пример |
|---|---|---|---|---|
| Имя, как обращаться | name | Луна | нет | Луна |
| Город | city | Астрахань | да | Астрахань |
| Часовой пояс | tz | Europe/Astrakhan | да | Europe/Astrakhan |
| Возраст | age |  | нет | 17 |
| Время подъёма | wake | 07:30 | да | 07:30 |
| Устройство | device | Windows | да | Windows |
| Предпочитаемый агент | agent |  | нет | claude |
| Канал | channel | @VioraStudio | нет | @VioraStudio |
