# План доработки Viora Studio: V4 в V5

Источники: Viora Studio V4, claude-video, Agent-Reach, social-media-skills,
marketing-skills (kostja94), marketingskills (Corey Haines), claude-skills.

Главная цель: слабая модель должна выдавать пост уровня сильной модели.
Способ: всё, что можно проверить кодом, проверяет код. Модель держит вкус, а не список правил.

## Блок А. Упаковка и обнаружение (пять ошибок со скрина)

| № | Что делаем | Откуда взято |
|---|---|---|
| A1 | Папка viora-studio стала viora-studio, name совпадает с папкой | спека Agent Skills |
| A2 | version и triggers уехали под metadata, триггеры внутри description | marketingskills/AGENTS.md |
| A3 | Пути обнаружения .claude/skills, .agents/skills, .cursor/skills | marketing-skills README |
| A4 | LICENSE вида MIT | все четыре пакета |
| A5 | .claude-plugin/plugin.json, marketplace.json, .skillignore | claude-video, social-media-skills |
| A6 | Под-скиллы research и video получили спека-фронтматтер | спека |

## Блок Б. Оптимизация под слабые модели (главный упор)

| № | Что делаем | Зачем |
|---|---|---|
| Б1 | tools/viora.py: один вход вместо шести скриптов | слабая модель не путается в командах |
| Б2 | --fix в линтере: сам чинит тире, стрелки, буллеты, футер | модель плохо чинит по описанию |
| Б3 | tools/route.py: текст задачи в один файл для чтения | убирает угадывание из 20 файлов |
| Б4 | Честная таблица размеров, генерируется скриптом | в V4 цифры врали почти втрое |
| Б5 | Один рабочий каталог во всех командах плюс гард на путь | claude-video |
| Б6 | QUICKCARD переписан как настоящий тир ноль | тир ноль решает задачу целиком |

## Блок В. Качество текста (порт из четырёх пакетов)

| № | Что делаем | Откуда |
|---|---|---|
| В1 | tools/score_post.py: 0-100 по пяти критериям на цифрах канала | post-scorer |
| В2 | Счёт человечности и новые ИИ-следы в линтере | content-humanizer |
| В3 | Шесть архетипов крючка плюс генератор строк | hook-generator |
| В4 | reference/frameworks.md: PAS, AIDA, BAB, STAR, SLAY под Telegram | post-formatter, copywriting |

| В8 | tools/memory.py: память пишет скрипт, а не руки | skillopt-sleep |

## Порядок работы

1. Блок А целиком.
2. Блок В8 и В1, потому что на них опирается остальное.
3. Блок Б2, Б1, Б3.
4. Остальной блок В: тексты reference.
5. Блок Б4 и Б6.
6. Блок Г: тесты, evals, валидатор, полный прогон.
7. Самопроверка: все тесты, проверка тире по всей папке, сборка промптов.
