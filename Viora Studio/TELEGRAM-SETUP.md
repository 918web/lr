# Телеграм: три шага

Никаких ботов, никакого MCP, никаких строк сессии руками. Телеграм внутри самого скилла.

## Шаг 1. Запустить

Открой папку поставки, правый клик по пустому месту, «Открыть в терминале», и вставь строку целиком:

```
powershell -ExecutionPolicy Bypass -File .\start-watch.ps1
```

Мак и линукс: `sh start-watch.sh`

## Шаг 2. QR с телефона

В консоли появится QR-код и ссылка под ним. Открой Телеграм на телефоне:
Настройки, Устройства, Подключить устройство, наведи камеру на код.
Код живёт около минуты, потом консоль нарисует новый. Если стоит двухфакторка,
консоль спросит пароль облака. Один раз в жизнь.

Нет камеры под рукой: та же ссылка `tg://login?...` открывается в Telegram Desktop,
где вход уже есть. Совсем старый путь по номеру и коду: `start-watch.ps1 login phone`.

Дальше смена идёт сама. Напиши себе в Избранное:

```
виора как дела
```

Ответ придёт сразу, реплаем на твоё сообщение. Слеш не нужен: `виора`, `viora`,
`/viora` и `/виора` работают одинаково.

## Шаг 3. Один раз: автозапуск

```
powershell -ExecutionPolicy Bypass -File .\start-watch.ps1 autostart
```

Мак и линукс: `sh start-watch.sh autostart`

Дальше всё само после каждого включения: сторож поднимается без окна, лог пишет
в рабочую папку. На Windows это задача планировщика при входе, на маке LaunchAgent
с перезапуском, на линуксе systemd --user. Убрать: `start-watch.ps1 autostart remove`.

## Что творится внутри

1. Запускатель ищет Python: `python`, `py -3`, `python3`.
2. Подхватывает ключи из `secrets/watch.env`.
3. `tg.py setup` ставит telethon и qrcode, если их нет, и зовёт вход по QR, если сессии нет.
4. Строка сессии ложится в `secrets/watch.env` сама, с правами только для тебя.
5. Сторож `tg_watch.py` держит соединение один: пишет lock-файл с сердцебиением,
   второй экземпляр не стартует. Все отправки от агента идут через него.
6. Сторож слушает только Избранное и только сообщения с префиксом или ответы реплаем.
   Фото и документы до 20 МБ качает в рабочую папку, альбом собирает в одну заявку.
7. Раз в минуту смотрит расписание и шлёт напоминания. Комп спал меньше трёх часов:
   пропущенное догоняет один раз.

Личные заметки в Избранном никуда не уходят: без префикса сторож их не видит.

## Кто отвечает

| Что написал | Кто ответил | Нужен ли агент |
| --- | --- | --- |
| `виора как дела`, `виора`, `виора что` | сторож сам, мгновенно | нет |
| `виора пк`, `виора погода`, `виора утро` | сторож через life.py | нет |
| `виора напоминай 08:00 утро` | сторож через schedule.py | нет |
| `виора реши` плюс фото | agent.py: твой Claude Code, Codex, Antigravity или Gemini CLI | да, любой из четырёх |
| `виора пост про ...` | agent.py по пайплайну скилла, черновик через линтер, карточкой реплаем | да |
| `виора пуб`, `виора правь короче`, `виора отложи 20:30`, `виора стоп` | сторож сам: публикует черновик из папки drafts знак в знак, переписывает мозгом, откладывает, отменяет | пуб и стоп нет, правь да |

Нет ни одного CLI агента: сторож пробует ключ из `secrets/ai.env`. Нет и ключа:
отдаёт каркас и ждёт, когда ты заберёшь заявку в редакторе командой `tg.py next`.
Какой агент найден, показывает `doctor`. Предпочтение задаётся в профиле:
`python3 tools/memory.py profile set агент=codex`.

## Если что-то не так

Проверить всё разом:

```
powershell -ExecutionPolicy Bypass -File .\start-watch.ps1 doctor
```

Покажет строки: telethon, qrcode, ключи api, строка сессии, канал, сторож жив или нет
и его pid, outbox пуст или ждёт, размер media, последний heartbeat, автозапуск
установлен или нет, какой агент найден. Рядом с каждой стоит, что делать.

| Строка в консоли | Что делать |
| --- | --- |
| Не нашёл Python 3 | Поставь с python.org, галка Add Python to PATH |
| нет строки сессии | `.\start-watch.ps1 login` |
| строка сессии не подошла | `.\start-watch.ps1 login`, вход перезапишется |
| ключи api нет в secrets/watch.env | Верни строки `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` |
| сторож уже работает: pid ... | Второй запуск не нужен, первый жив. Закрой это окно |
| сторож нет, lock устарел | Сторож упал или комп спал: запусти шаг 1 снова или подожди автозапуск |
| outbox ждёт N строк | Сторож не отправил записки агента: смотри watch.log в рабочей папке |
| агент нет | Поставь claude, codex, agy или gemini, или положи ключ в secrets/ai.env |
| Подключение не доведено до конца | Смотри строки выше, там причина |

Лог сторожа: `watch.log` в рабочей папке, ротация на 1 МБ, запасной файл `watch.log.1`.
Путь к папке печатает `doctor` строкой «рабочая папка».

## Проверка за пять минут

1. `start-watch`, QR с телефона, консоль пишет «вошёл как ...» и «Смена началась».
2. В Избранное: `виора как дела`. Ответ реплаем в ту же секунду: `VIORA НА СМЕНЕ ...`.
3. Фото задачи плюс подпись `виора реши`. Сначала реплай `VIORA ВЗЯЛ, ДУМАЮ`,
   потом `VIORA РЕШЕНИЕ` с ответом по картинке.
4. `виора место`, потом `виора погода`. Два ответа без модели: диск и прогноз.
   Погода без города в профиле честно попросит записать город.
5. `виора напоминай 08:00 утро`. Ответ `VIORA НАПОМИНАНИЕ` со списком.
   Проверка с компа: `python3 tools/schedule.py list`.
6. `start-watch autostart`, перезагрузка, снова `виора как дела` без запуска руками.
   `doctor` показывает «автозапуск установлен» и «сторож жив».
7. Открой папку в Codex, потом в Antigravity, потом в Claude Code. В каждой спроси
   «что в памяти канала». Ответ один и тот же файл: `viora-studio/memory/post-log.md`.

## Команды на каждый день

Всё пишется в Избранное, первое слово `виора` или `viora`, слеш по желанию.

| Сообщение | Что будет |
| --- | --- |
| `виора как дела` | Ответ сразу, смена жива |
| `виора` | Карточка со всеми командами |
| `виора что` | Что в работе сейчас |
| `виора пост про абузы на курсор` | Заявка на пост, черновик придёт реплаем |
| `виора пуб` | Публикуем черновик в канал |
| `виора правь убери воду` | Правка черновика |
| `виора отложи 20:30` | Отложенная публикация |
| `виора стоп` | Отмена заявки |
| `виора реши` плюс фото | Ответ по картинке |
| `виора пк` | Место на диске, память, батарея |
| `виора погода` | Погода по городу из профиля |
| `виора утро` | Утренний дайджест |
| `виора напоминай 08:00 утро` | Дайджест каждое утро в восемь |

## Где что лежит

- `secrets/watch.env` ключи и строка сессии. Никому не показывать.
- Рабочая папка: `%USERPROFILE%\.local\state\viora-studio` на Windows,
  `~/.local/state/viora-studio` на маке и линуксе. Внутри ящик заявок, черновики,
  outbox, lock, `watch.log` и папка `media` со вложениями.
- Профиль, напоминания и память канала: `viora-studio/memory/`, едут со скиллом.

Файл `make_session.py` и `secrets/telegram.env`, если они ещё где-то лежат, больше
не нужны. Удаляй без жалости: вход теперь внутри скилла, второго процесса нет.
